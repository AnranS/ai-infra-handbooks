从零训练小模型的训练循环里，有三处很容易写错。用 numpy 实现：

1. `lr_at(step, lr, min_lr, warmup, max_steps)`：线性 warmup，之后余弦衰减到 `min_lr`：
    - `step < warmup` 时是 `lr × (step + 1) / warmup`（第 0 步就不为 0）；
    - 之后 `progress = (step − warmup) / max(1, max_steps − warmup)`，学习率是 `min_lr + 0.5 × (lr − min_lr) × (1 + cos(π × progress))`；
2. `clip_by_global_norm(grads, max_norm)`：`grads` 是一组 numpy 数组。先算**所有**梯度拼在一起的 L2 范数（全局范数），超过 `max_norm` 时把每个梯度都乘以 `max_norm / (全局范数 + 1e-6)`，否则不动。返回 `(新的梯度列表, 裁剪前的全局范数)`，不修改传入的数组；
3. `decay_groups(named_shapes)`：`named_shapes` 是 `{参数名: 形状}`。二维及以上的参数（矩阵、词嵌入）做权重衰减，一维的（归一化层的增益、偏置）不做；返回 `(做衰减的名字列表, 不做的名字列表)`，各自保持原来的顺序。

```python
lr_at(0, 3e-3, 3e-4, 60, 600)        # 5e-05：warmup 的第一步
lr_at(600, 3e-3, 3e-4, 60, 600)      # 0.0003：衰减到 min_lr
```

<!-- 题解 -->
warmup 让学习率从很小慢慢升到峰值：训练刚开始时 Adam 的二阶矩估计还不准、参数是随机的，大学习率容易让 loss 发散。余弦衰减在后期把学习率降到峰值的十分之一左右，让模型收敛到更低的 loss。

梯度裁剪按**全局**范数统一缩放，所有参数的梯度乘同一个系数，更新方向不变、只是步长变小；逐个张量裁剪会改变方向。返回裁剪前的范数，是因为它是训练监控里最有用的信号之一：loss 突刺之前往往先出现梯度范数的尖峰。`+ 1e-6` 防止除零。

权重衰减只作用于矩阵：归一化层的增益如果被衰减到 0，那一层的输出就被压没了；偏置和增益的数量很少，也不是过拟合的来源。
