不用 `json` 模块，实现 `loads(text)`，把 JSON 文本解析成 Python 对象，行为与 `json.loads` 一致：

- 对象 → `dict`，数组 → `list`，字符串 → `str`，`true`/`false`/`null` → `True`/`False`/`None`；
- 数字：整数 → `int`；带小数点或指数（`1.5`、`-2e3`、`1E-2`）→ `float`；不允许前导 0（`012`）、不允许 `+1`、`.5`、`1.`；
- 字符串转义：`\" \\ \/ \b \f \n \r \t` 和 `\uXXXX`（包括代理对 `\ud83d\ude00` 组合成一个字符）；字符串里不允许出现未转义的控制字符（码点小于 0x20）；
- 任意位置可以有空白（空格、`\t`、`\n`、`\r`）；
- 解析完之后如果还有多余的非空白字符，是错误。

出错时抛出 `ValueError`，信息里包含出错位置（字符下标），例如 `ValueError: 第 7 个字符：期望 ':'`。

递归下降：一个 `Parser` 类维护当前位置 `i`，每种值一个方法：

- `value()` 看当前字符分派：`{` → `obj()`，`[` → `arr()`，`"` → `string()`，`t/f/n` → 字面量，`-` 或数字 → `number()`；
- 数字用正则 `-?(0|[1-9]\d*)(\.\d+)?([eE][+-]?\d+)?` 在当前位置 `match`，有小数或指数部分就 `float()`，否则 `int()`；
- 字符串逐字符扫描，遇到 `\` 处理转义；`\uD800`–`\uDBFF` 后面必须紧跟 `\uDC00`–`\uDFFF`，组合成 `0x10000 + ((hi - 0xD800) << 10) + (lo - 0xDC00)`。
