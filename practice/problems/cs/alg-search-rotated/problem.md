一个升序数组在某个位置被旋转过（比如 `[0,1,2,4,5,6,7]` 变成 `[4,5,6,7,0,1,2]`），数组中**没有重复元素**。在 O(log n) 时间内找出 `target` 的下标，不存在返回 -1。

```python
search_rotated([4, 5, 6, 7, 0, 1, 2], 0)     # 4
search_rotated([4, 5, 6, 7, 0, 1, 2], 3)     # -1
search_rotated([1], 1)                       # 0
```

<!-- 题解 -->
旋转数组从中点切开后，**必有一半是有序的**。所以每轮：先判断哪一半有序（比较 `a[lo]` 和 `a[mid]`），再判断 target 是否落在那一半的范围内——落在就去那半边，否则去另一半。

判断有序要用 `a[lo] <= a[mid]`（带等号），否则只有两个元素时会判断错。目标是否在有序的一半里，要用**闭区间**判断（`a[lo] <= target < a[mid]`），边界包不包含直接决定了会不会漏解。

有重复元素时（比如 `[1,0,1,1,1]`）最坏会退化成 O(n)：`a[lo] == a[mid] == a[hi]` 时无法判断哪半有序，只能把 `lo` 往右挪一格。面试里这是常见的追问。
