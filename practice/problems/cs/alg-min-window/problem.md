给字符串 `s` 和 `t`，返回 `s` 中涵盖 `t` **所有字符（含重复次数）**的最短子串；不存在则返回空串。有多个最短答案时返回**最靠左**的。

```python
min_window("ADOBECODEBANC", "ABC")    # "BANC"
min_window("a", "aa")                 # ""
```

<!-- 题解 -->
"最短满足条件"型的滑动窗口：右指针扩张直到窗口覆盖了 `t`，然后**一满足就收缩左边界**并记录答案。

判断"是否覆盖"不要每次都比较两个计数字典（那样是 O(字符集)），而是维护一个 `missing` 计数：初始为 `len(t)`，每当某个**还欠着的**字符进入窗口就减一（`need[ch] > 0` 时才减），出窗口时反过来加回去。`missing == 0` 就说明覆盖了。

时间 O(|s| + |t|)，空间 O(字符集)。容易错的地方：收缩时先记录答案再移动左边界；`need` 用 `Counter` 后，不在 `t` 里的字符计数会变成负数，这正好让"多余字符"自然被跳过。
