用 `T` 类（`val`、`left`、`right`）实现：

1. `is_bst(root)`：判断是不是**严格**的二叉搜索树（左子树所有值 < 根 < 右子树所有值）；
2. `kth_smallest(root, k)`：返回第 k 小的值（k 从 1 开始，越界返回 `None`）。两个函数都要能处理很深的树（不能递归到两万层）。

```python
is_bst(T(2, T(1), T(3)))            # True
is_bst(T(5, T(1), T(4, T(3), T(6))))# False：4 的子树里有 3，小于根 5
kth_smallest(T(3, T(1, None, T(2)), T(4)), 2)   # 2
```

<!-- 题解 -->
验证 BST 最常见的错误是"只比较父子节点"——`T(5, T(1), T(4, T(3), T(6)))` 里每对父子都合法，但 4 整棵子树都应该大于 5。正确做法有两种：（1）**给每个节点传一个允许的区间** `(low, high)`，往左走收紧上界、往右走收紧下界；（2）**中序遍历必须严格递增**，一边遍历一边和前一个值比较。

第 k 小用中序遍历，数到第 k 个就可以停——用迭代写法能真正做到"提前退出"，递归就得靠异常或标志位。

这里两个函数都用显式栈，因为退化成链的 BST（按有序数据插入）深度等于节点数。真实系统里的平衡树（红黑树、B+ 树）就是为了解决这个问题；Python 标准库没有平衡树，需要有序结构时一般用 `sortedcontainers` 或者"排好序的列表 + `bisect`"。
