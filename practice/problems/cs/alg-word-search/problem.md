在字符网格里找一个单词：从任意格子出发，每步走到上下左右相邻的格子，**同一个格子不能重复使用**。

`exist(board, word)` 返回能否找到（空单词返回 `True`），并且**不能修改** `board`。

```python
board = [["A", "B", "C", "E"],
         ["S", "F", "C", "S"],
         ["A", "D", "E", "E"]]
exist(board, "ABCCED")     # True
exist(board, "SEE")        # True
exist(board, "ABCB")       # False：B 不能重复用
```

<!-- 题解 -->
回溯的网格版本：从每个格子出发试一次，每步检查边界、字符是否匹配、是否已访问；匹配就标记为已访问、递归四个方向、回来再**撤销标记**。

"不能修改 board"意味着要用一个单独的 `visited` 集合（常见题解直接把字符改成 `#` 再改回来，那是原地标记的技巧，省内存但有副作用）。

剪枝能大幅提速：（1）单词长度超过格子总数直接返回 False；（2）统计整张表的字符频次，如果单词里某个字符的个数超过表里的，直接返回 False；（3）如果单词的最后一个字符在表里比第一个少，就把单词反过来搜。

复杂度最坏是 O(格子数 × 4^单词长度)，剪枝是实战里能不能跑过的关键。
