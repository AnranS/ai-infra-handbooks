两道二维 DP 的模板题：

1. `edit_distance(a, b)`：把 `a` 变成 `b` 最少需要几次操作（插入、删除、替换各算一次）；
2. `lcs(a, b)`：最长公共**子序列**的长度（子序列不要求连续）。

```python
edit_distance("horse", "ros")          # 3
edit_distance("intention", "execution")# 5
lcs("abcde", "ace")                    # 3
```

<!-- 题解 -->
编辑距离的状态：`f[i][j]` 表示 `a` 的前 i 个变成 `b` 的前 j 个最少要几步。初始值是全删（`f[i][0] = i`）和全插（`f[0][j] = j`）。转移：字符相同就继承左上角 `f[i-1][j-1]`；不同就取"删（`f[i-1][j]`）、插（`f[i][j-1]`）、替（`f[i-1][j-1]`）"三者最小再加一。

LCS 的骨架一样：相同时 `f[i-1][j-1] + 1`，不同时 `max(f[i-1][j], f[i][j-1])`。

两点常见追问：（1）**空间优化**——只依赖上一行，可以压成两行或一行（一行时要用一个临时变量存住"左上角"的旧值）；（2）**要还原操作序列**时，要么保留整张表回溯，要么记录每一步的选择。

工程上的用处：评测里的字错率（WER/CER）、diff 工具、投机解码里比较草稿与目标序列的第一个分歧点。
