给数组和窗口大小 `k`，返回每个窗口里的最大值组成的列表。要求 O(n)。

```python
sliding_max([1, 3, -1, -3, 5, 3, 6, 7], 3)    # [3, 3, 5, 5, 6, 7]
sliding_max([1], 1)                            # [1]
```

<!-- 题解 -->
**单调队列**：双端队列里存**下标**，对应的值从队首到队尾单调递减。每步做三件事：

1. 队尾所有值 ≤ 新元素的下标都弹掉（它们永远不可能再当最大值了——新元素更大且更晚出窗口）；
2. 新下标入队尾；
3. 队首下标若已滑出窗口（`<= i - k`）就弹掉；窗口形成后（`i >= k - 1`）记录队首对应的值。

每个下标进队一次、出队一次，所以是 O(n)，哪怕代码里有嵌套的 `while`。

存下标而不是值，是为了能判断"是否滑出窗口"。最小值只要把比较符号反过来。变体：窗口内最大值与最小值之差不超过 limit 的最长子数组（两个单调队列）。
