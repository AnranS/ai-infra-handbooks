求数组里连续非空子数组的**最大乘积**。数组可能含负数和 0。

```python
max_product([2, 3, -2, 4])        # 6
max_product([-2, 0, -1])          # 0
max_product([-2, 3, -4])          # 24
```

<!-- 题解 -->
和"最大子数组和"的区别在于：乘上一个负数会让最大值变最小、最小值变最大。所以要**同时维护以当前元素结尾的最大值和最小值**：

```text
新的最大 = max(x, 最大 * x, 最小 * x)
新的最小 = min(x, 最大 * x, 最小 * x)
```

两者必须用**上一轮的值**同时更新（先把旧的最大值存下来），否则第二行会用到已经更新过的最大值。

0 会把乘积清零，上面的公式已经自动处理了（`max(x, ...)` 让它从 x 重新开始）。

这是"状态不止一个"的典型例子：一维 DP 里状态有时需要两三个分量（最大/最小、持有/不持有股票、买卖次数）。
