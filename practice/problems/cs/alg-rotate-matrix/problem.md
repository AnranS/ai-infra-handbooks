1. `rotate(matrix)`：把 n×n 矩阵**原地**顺时针旋转 90 度（不返回值）；
2. `spiral(matrix)`：按顺时针螺旋顺序返回矩阵里的所有元素（矩阵可以不是方阵）。

```python
m = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
rotate(m)
m                # [[7, 4, 1], [8, 5, 2], [9, 6, 3]]
spiral([[1, 2, 3], [4, 5, 6], [7, 8, 9]])    # [1, 2, 3, 6, 9, 8, 7, 4, 5]
```

<!-- 题解 -->
原地旋转的技巧是**先转置、再左右翻转**：转置把 `(i, j)` 换成 `(j, i)`（只遍历上三角，否则会换回来），再把每一行反转就是顺时针 90 度。逆时针则是"先转置再上下翻转"。

螺旋遍历维护四个边界 `top / bottom / left / right`，每走完一条边就收缩对应的边界。**每走一条边之前都要检查边界是否还成立**（`if top <= bottom` / `if left <= right`），否则单行或单列的矩阵会被重复遍历。

这两道题考的是"能不能把二维下标想清楚"，工程上对应张量的转置与布局变换——比如注意力里 `[B, H, S, D]` 和 `[B, S, H, D]` 之间的转置，以及 CUDA 里的分块转置（见 [矩阵转置](cuda://kernels/transpose/)）。
