数组 `height` 的每个元素是一根竖线的高度，选两根线与 x 轴围成容器，求能盛的最多水量（面积 = 两线间距 × 较矮的高度）。

```python
max_area([1, 8, 6, 2, 5, 4, 8, 3, 7])    # 49
max_area([1, 1])                          # 1
```

<!-- 题解 -->
两层循环是 O(n²)。**相向双指针**：从最宽的一对开始（左右两端），每次移动**较矮**的那一边。

为什么移动矮的一边是对的？当前面积受限于矮的那条线。如果移动高的那边，宽度减小、高度最多还是那条矮线，面积不可能变大；只有移动矮的那边，才有可能换来更高的线。所以每一步都安全地丢掉了一批不可能更优的组合，O(n) 扫完。

这是"贪心 + 双指针"的典型：每次移动都有严格的理由，证明"被丢掉的那些组合不可能是最优解"。相向双指针的其他常见题：有序数组两数之和、验证回文串、反转字符串里的元音。
