1. `can_finish(n, prerequisites)`：`prerequisites` 里 `(a, b)` 表示"学 a 之前必须先学 b"，判断能否修完所有课；
2. `find_order(n, prerequisites)`：返回一个可行的修课顺序（可选的课**按编号从小到大**），不可能则返回 `[]`。

```python
can_finish(2, [(1, 0)])              # True
can_finish(2, [(1, 0), (0, 1)])      # False
find_order(4, [(1, 0), (2, 0), (3, 1), (3, 2)])   # [0, 1, 2, 3]
```

<!-- 题解 -->
和拓扑排序是同一道题，只是把边的方向读反了：`(a, b)` 表示 `b -> a`（先修 b 才能修 a）。**把题目的依赖关系翻译成边的方向**是这道题最容易出错的地方，写之前先在纸上画一条边确认方向。

用入度表 + 最小堆（保证编号小的先出），出队数少于 n 就说明有环。DFS 三色标记也能判环：白（没访问）、灰（正在访问的路径上）、黑（已完成），遇到灰色节点说明有环。

工程对应：算子的依赖图、任务编排（Airflow 这类 DAG 调度）、模块的编译顺序、以及推理框架构图时的合法性检查。
