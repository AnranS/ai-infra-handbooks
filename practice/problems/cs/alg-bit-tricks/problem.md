1. `single_number(nums)`：除一个数字只出现一次外，其余都出现两次，找出那个数（要求 O(1) 额外空间）；
2. `count_bits(n)`：返回 `0..n` 每个数的二进制里 1 的个数组成的列表；
3. `is_power_of_two(n)`：判断是不是 2 的幂（`n <= 0` 返回 `False`）。

```python
single_number([4, 1, 2, 1, 2])     # 4
count_bits(5)                      # [0, 1, 1, 2, 1, 2]
is_power_of_two(16)                # True
```

<!-- 题解 -->
三个最常考的位运算技巧：

- **异或**：`x ^ x == 0`、`x ^ 0 == x`，且满足交换律，所以把所有数异或起来，成对的互相抵消，剩下的就是答案；
- **`n & (n - 1)`** 会把最低位的 1 清掉，于是"统计 1 的个数"可以循环做这个操作；而 `count_bits` 用 DP 更快：`f[i] = f[i >> 1] + (i & 1)`（右移一位相当于去掉最低位）；
- **2 的幂**的二进制只有一个 1，所以 `n > 0 and n & (n - 1) == 0`。

工程里位运算的用处：用位掩码表示一组开关（CUDA 里的 `__ballot_sync`、注意力的掩码）、对齐（`(x + align - 1) & ~(align - 1)` 向上取整到 2 的幂）、以及哈希与布隆过滤器。Python 的整数是任意精度的，没有溢出，但也因此比 C 慢很多。
