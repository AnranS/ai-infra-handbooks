title: 和为 k 的子数组

统计数组里**和恰好为 k** 的连续子数组个数。数组元素可以是负数。

```python
subarray_sum([1, 1, 1], 2)          # 2
subarray_sum([1, 2, 3], 3)          # 2：[1,2] 和 [3]
subarray_sum([1, -1, 0], 0)         # 3：[1,-1]、[0]、[1,-1,0]
```

<!-- 题解 -->
两层循环枚举所有子数组是 O(n²)。关键的变形是：子数组 `[i, j)` 的和 = `前缀和[j] - 前缀和[i]`，所以"和为 k"等价于"存在多少个 i 使 `前缀和[i] == 前缀和[j] - k`"。

于是边遍历边用哈希表记录每个前缀和出现过几次：遇到位置 j 时，先查 `cur - k` 出现了几次、累加进答案，再把 `cur` 记进表里。初始要放一个 `{0: 1}`，表示"空前缀"，否则从下标 0 开始的子数组会被漏掉。

**有负数时不能用滑动窗口**：窗口和不再单调，收缩左边界不一定让和变小。这是这道题和"和 ≥ target 的最短子数组"的根本区别。
