1. `coin_change(coins, amount)`：用任意多枚给定面额的硬币凑出 `amount`，返回最少硬币数，凑不出返回 -1（`amount = 0` 返回 0）；
2. `count_ways(coins, amount)`：凑出 `amount` 的**组合**数（`[1,2]` 和 `[2,1]` 算同一种）。

```python
coin_change([1, 3, 4], 6)      # 2：3 + 3
coin_change([2], 3)            # -1
count_ways([1, 2, 5], 5)       # 4
```

<!-- 题解 -->
这是**完全背包**：每种硬币可以用无限次，所以一维数组的内层循环用**正序**（和 0-1 背包的倒序正好相反）。

`coin_change` 的状态是"凑出 i 元最少要几枚"，初始 `f[0] = 0`、其余为无穷大，转移 `f[i] = min(f[i], f[i - coin] + 1)`。

`count_ways` 要数**组合**（不区分顺序），所以**外层遍历硬币、内层遍历金额**；如果反过来（外层金额、内层硬币），数的就是**排列**数（`1+2` 和 `2+1` 算两种）。这是完全背包里最容易记混的一点。

贪心在这里是错的：面额 `[1, 3, 4]` 凑 6，贪心先拿 4 再拿两个 1 共 3 枚，最优是两个 3 共 2 枚。这正是"贪心要能证明"的经典反例。
