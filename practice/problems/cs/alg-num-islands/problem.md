`grid` 是由 `0`（水）和 `1`（陆地）组成的二维列表，上下左右四联通。实现：

1. `num_islands(grid)`：岛屿数量；
2. `max_area(grid)`：最大岛屿的面积。

两个函数都**不能修改**传入的 `grid`。

```python
g = [[1, 1, 0], [0, 1, 0], [0, 0, 1]]
num_islands(g)     # 2
max_area(g)        # 3
```

<!-- 题解 -->
标准的网格搜索：遍历每个格子，遇到没访问过的陆地就从它出发做一次 BFS 或 DFS，把整座岛标记为已访问。岛屿数就是发起搜索的次数，面积就是每次搜索访问到的格子数。

两个关键点：（1）**访问标记要在入队时打**，不是出队时打，否则同一个格子会被重复入队，最坏退化成指数级；（2）题目说不能改原数组，所以要用一个单独的 `visited` 集合或矩阵（很多题解直接把 `1` 改成 `0`，那是"原地标记"，更省内存但有副作用）。

用 DFS 递归时要注意深度：一整张 500×500 全是陆地的图，递归深度可能到 25 万，Python 会爆栈——所以这里写**迭代**（用栈或队列）。并查集也能做，适合"边加边问连通分量"的动态场景。
