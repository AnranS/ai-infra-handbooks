返回一个数组 `out`，其中 `out[i]` 等于 `nums` 里**除了 `nums[i]` 之外**所有元素的乘积。要求 **不使用除法**，时间 O(n)。

```python
product_except_self([1, 2, 3, 4])      # [24, 12, 8, 6]
product_except_self([-1, 1, 0, -3, 3]) # [0, 0, 9, 0, 0]
```

<!-- 题解 -->
不能用除法的原因是数组里可能有 0（一个 0 时只有它的位置非零，两个 0 时全是 0）。

标准解法是**前缀积 × 后缀积**：`out[i] = (nums[0..i) 的积) × (nums(i..n) 的积)`。先从左往右扫一遍把前缀积写进 `out`，再从右往左扫一遍，用一个变量累乘后缀积并乘进 `out[i]`。两遍扫描、O(1) 额外空间（输出数组不算）。

这也是前缀和思想换成乘法的例子：任何"满足结合律、可以增量累积"的运算都能这么做（和、积、异或、最大值、最小值）。注意乘法没有逆运算可用（0 不能除），所以要用两遍扫描而不是"总积除以自己"。
