1. `shortest_path(grid, start, end)`：`grid` 里 `0` 可走、`1` 是障碍，四联通，返回从 `start` 到 `end` 的最少步数（起点终点相同为 0，不可达返回 -1）；
2. `rotting_time(grid)`：多源 BFS。`grid` 里 `0` 是空、`1` 是新鲜、`2` 是腐烂，每分钟腐烂会传染四联通的新鲜格子，返回全部腐烂所需的分钟数；有永远腐烂不了的返回 -1；本来就没有新鲜的返回 0。

```python
shortest_path([[0, 0], [1, 0]], (0, 0), (1, 1))     # 2
rotting_time([[2, 1, 1], [1, 1, 0], [0, 1, 1]])     # 4
```

<!-- 题解 -->
无权图的最短路就是 BFS：第一次访问到某个格子时的距离一定是最短的（队列按距离分层）。**访问标记在入队时打**，否则同一个格子会被多次入队。

多源 BFS 只是把所有起点一次性放进初始队列，其余完全一样——这等价于加一个虚拟源点连到所有起点。腐烂橘子、离每个 0 最近的 1、火势蔓延都是这类题。返回的分钟数是"层数 - 1"（初始层是第 0 分钟），最后还要检查有没有剩下的新鲜格子。

带权图要换 Dijkstra（堆），边权只有 0 和 1 时可以用 **0-1 BFS**（双端队列，权为 0 的从队首入、为 1 的从队尾入），复杂度仍是 O(V+E)。
