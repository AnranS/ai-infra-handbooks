只能向右或向下走：

1. `unique_paths(m, n)`：从左上角到右下角有多少条不同路径；
2. `paths_with_obstacles(grid)`：`grid` 里 `1` 是障碍，返回路径数（起点或终点是障碍则为 0）；
3. `min_path_sum(grid)`：每个格子有代价，返回从左上到右下的最小代价和（空网格返回 0）。

```python
unique_paths(3, 7)                                   # 28
paths_with_obstacles([[0, 0, 0], [0, 1, 0], [0, 0, 0]])   # 2
min_path_sum([[1, 3, 1], [1, 5, 1], [4, 2, 1]])      # 7
```

<!-- 题解 -->
三题共用一个二维 DP 骨架：`f[i][j] = f[i-1][j] (+|min) f[i][j-1]`，第一行只能从左边来、第一列只能从上面来。

因为每个格子只依赖"上面"和"左边"，可以压成**一维滚动数组**：从左到右更新时，`f[j]` 的旧值正好是"上面"，`f[j-1]` 的新值正好是"左边"。空间从 O(mn) 降到 O(n)。

障碍版本的要点是：遇到障碍就把 `f[j]` 置 0（这条路走不通），并且起点是障碍时直接返回 0。

`unique_paths` 其实有组合数公式 `C(m+n-2, m-1)`，面试时可以提一句；但 DP 的写法更通用（加障碍、加代价都只是改一行）。
