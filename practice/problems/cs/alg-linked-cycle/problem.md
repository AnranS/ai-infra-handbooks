1. `has_cycle(head)`：链表里有没有环；
2. `cycle_start(head)`：返回入环的那个**节点**，无环返回 `None`。

```python
# 1->2->3->4->2(回到第二个节点)：has_cycle 为 True，cycle_start 返回值为 2 的节点
```

<!-- 题解 -->
快慢指针（Floyd 判圈）：慢指针一次一步、快指针一次两步。有环时快指针一定会从后面追上慢指针（每步缩小一格距离）；无环时快指针先到达末尾。

入环点的推导：设头到入环点 a 步、入环点到相遇点 b 步、环长 c。相遇时慢走了 `a + b`，快走了 `2(a + b)`，且快比慢多走整数圈：`2(a+b) - (a+b) = kc`，即 `a + b = kc`，于是 `a = kc - b`——**从头出发走 a 步，和从相遇点出发走 a 步（绕若干圈后正好到入环点），两者会在入环点相遇**。所以相遇后让一个指针回到头，两个指针同速前进，再次相遇的地方就是入环点。

用哈希表记录访问过的节点也能做，但那是 O(n) 空间；面试要的是 O(1) 的这个。
