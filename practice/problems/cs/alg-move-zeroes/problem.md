把数组里所有的 0 移到末尾，其余元素**保持相对顺序**，要求**原地**修改（额外空间 O(1)）。函数直接修改传入的列表，不返回值。

```python
a = [0, 1, 0, 3, 12]
move_zeroes(a)
a                      # [1, 3, 12, 0, 0]
```

<!-- 题解 -->
经典的**快慢指针**：慢指针 `slow` 指向下一个非零元素该放的位置，快指针扫一遍数组，遇到非零就放到 `slow` 并让 `slow` 前进。扫完之后把 `slow` 之后的位置全部填 0。

更省事的写法是交换：`a[slow], a[fast] = a[fast], a[slow]`，这样不需要第二趟填零，而且写入次数更少（零本来就在后面时完全不写）。

原地、保持相对顺序、O(1) 空间——这三个要求同时出现时，几乎都是双指针。类似的题：删除有序数组里的重复项、按奇偶重排、颜色分类（三指针）。
