把二叉树转成字符串再还原回来（用 `T` 类，值都是整数）：

1. `serialize(root)`：转成字符串。用层序遍历，空节点写 `#`，元素之间用逗号分隔，**末尾多余的 `#` 要去掉**；空树返回空串；
2. `deserialize(data)`：从字符串还原成树。

`deserialize(serialize(root))` 必须和原树结构完全一致。

```python
serialize(T(1, T(2), T(3, T(4), T(5))))    # "1,2,3,#,#,4,5"
deserialize("1,2,3,#,#,4,5")               # 还原成同一棵树
serialize(None)                            # ""
```

<!-- 题解 -->
层序序列化用队列：出队一个节点，写下它的值，再把左右孩子（可能是 `None`）入队；`None` 写成 `#` 且不再展开它的孩子。反序列化也用队列：按顺序取值，遇到非 `#` 就建节点并挂到当前父节点上。

两个细节：（1）**末尾的 `#` 要裁掉**，否则字符串会膨胀（一棵满二叉树的叶子后面全是 `#`）；（2）反序列化时要判断数据是否已经读完，不能越界。

前序 + `#` 占位也能唯一还原（递归写法更短），但层序的结果更易读，也更接近真实的树形结构传输。

工程对应：模型计算图的序列化（ONNX、TorchScript）、Radix Cache 的持久化、以及跨进程传递树形元数据——这类场景通常直接用 protobuf 或 flatbuffers，但"用什么占位、怎么保证能唯一还原"的问题是一样的。
