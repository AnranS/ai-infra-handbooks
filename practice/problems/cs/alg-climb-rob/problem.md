两道最基础的一维 DP，都要求 O(1) 额外空间：

1. `climb_stairs(n)`：每次爬 1 或 2 级，爬到第 n 级有几种走法（`n = 0` 返回 1）；
2. `rob(nums)`：不能偷相邻的两家，求能偷到的最大金额；
3. `rob_circle(nums)`：房子围成一圈（首尾也相邻），求最大金额。

```python
climb_stairs(4)          # 5
rob([2, 7, 9, 3, 1])     # 12
rob_circle([2, 3, 2])    # 3：不能同时偷首尾
```

<!-- 题解 -->
爬楼梯就是斐波那契：`f[i] = f[i-1] + f[i-2]`，只依赖前两个值，所以两个变量滚动即可。

打家劫舍的状态是"前 i 家能偷到的最大值"，转移是 `f[i] = max(f[i-1], f[i-2] + nums[i])`（不偷第 i 家 / 偷第 i 家）。同样只依赖前两个。

环形的技巧：首尾不能同时偷，所以答案是"**不偷最后一家**"和"**不偷第一家**"两种情况的较大值，各跑一次线性版本。注意只有一家时要特判（两个切片都会是空的）。

这三道是所有一维 DP 的起点：能把状态、转移、初始值、滚动写法说清楚，后面的题都是同一套。
