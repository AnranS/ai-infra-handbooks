求数组里**连续非空**子数组的最大和，返回 `(最大和, 起点, 终点)`，区间是左闭右开 `[start, end)`。有多个答案时返回**起点最小**的；起点相同时返回**最短**的。

```python
max_subarray([-2, 1, -3, 4, -1, 2, 1, -5, 4])     # (6, 3, 7)
max_subarray([-3, -1, -2])                        # (-1, 1, 2)
```

<!-- 题解 -->
Kadane 算法：从左到右扫一遍，维护"以当前位置结尾的最大和" `cur`。新元素 `x` 要么接在前面的和后面（`cur + x`），要么自己另起一段（`x`）——取较大的那个。全局答案是所有 `cur` 里的最大值。

时间 O(n)、空间 O(1)。两个容易错的地方：（1）**全是负数时**答案是最大的那个负数，不是 0，所以 `best` 不能初始化成 0；（2）要返回区间时，另起一段的时刻就是新起点。

换个角度看，它也是最简单的动态规划：状态是"以 i 结尾的最大和"，转移是 `f(i) = max(f(i-1) + a[i], a[i])`。用前缀和看则是"当前前缀和减去前面出现过的最小前缀和"。
