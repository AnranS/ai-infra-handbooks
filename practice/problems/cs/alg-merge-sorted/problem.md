`a` 的前 `m` 个元素和 `b` 的前 `n` 个元素都是升序的，`a` 的长度是 `m + n`（后面 `n` 个位置是占位的 0）。把两个数组合并成一个升序数组，**原地**存进 `a`。

```python
a = [1, 2, 3, 0, 0, 0]
merge(a, 3, [2, 5, 6], 3)
a                    # [1, 2, 2, 3, 5, 6]
```

<!-- 题解 -->
从前往后合并需要把 `a` 的元素不断往后挪，是 O((m+n)²)。**从后往前**填就没有这个问题：`a` 的尾部本来就是空位，每次把两个数组当前最大的元素放进去。

三个指针：`i = m - 1`（a 的有效尾）、`j = n - 1`（b 的尾）、`k = m + n - 1`（写入位置）。循环到 `j < 0` 就可以停——此时 `b` 已经全部放完，`a` 剩下的部分本来就在正确的位置上。

这是归并排序的合并步骤，也是外排序（数据放不进内存时分块排序再多路归并）的基础。多路归并用堆，见[排序、堆与贪心](sort-heap-greedy.md)。
