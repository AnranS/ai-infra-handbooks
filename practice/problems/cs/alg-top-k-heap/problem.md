实现两种求"第 k 大"和"前 k 大"的方法：

1. `top_k_heap(nums, k)`：用大小为 k 的**小顶堆**，返回前 k 大的元素，按**从大到小**排列（`k <= 0` 或数组为空返回 `[]`，`k` 超过长度就返回全部）；
2. `kth_largest(nums, k)`：用**快速选择**返回第 k 大的元素（k 从 1 开始，越界返回 `None`）。不能直接调用 `sorted`。

```python
top_k_heap([3, 2, 1, 5, 6, 4], 2)      # [6, 5]
kth_largest([3, 2, 1, 5, 6, 4], 2)     # 5
kth_largest([1], 1)                    # 1
```

<!-- 题解 -->
**堆法**：遍历数组，堆不满就压入；满了就比较堆顶（当前第 k 大），比它大才替换（`heapreplace` 比先 pop 再 push 快一倍）。时间 O(n log k)、空间 O(k)。数据是流式的、或者 n 极大 k 很小时，这是唯一可行的做法。

**快速选择**：随机选一个枢轴，把数组分成"大于""等于""小于"三份，看第 k 大落在哪一份里，只递归那一份。平均 O(n)、最坏 O(n²)（随机枢轴让最坏几乎不会出现）。三路划分能优雅地处理大量重复元素。

面试时给出三种解法和取舍：全排序 O(n log n)（要全序时用）、堆 O(n log k)（k 小或流式）、快速选择 O(n) 平均（只要第 k 大）。推理里的 top-k 采样是同一个问题，GPU 上用并行归约或 `torch.topk` 实现。
