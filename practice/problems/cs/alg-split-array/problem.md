title: 二分答案：分块的最大值

把一个非负整数数组**按顺序**分成 `k` 个非空连续段，使每段和的最大值最小，返回这个最小的最大值。这正是分块 prefill 里"把一批请求切成几块、每块 token 数尽量均衡"的模型。

```python
split_array([7, 2, 5, 10, 8], 2)     # 18：[7,2,5] 和 [10,8]
split_array([1, 2, 3, 4, 5], 2)      # 9
split_array([1, 4, 4], 3)            # 4
```

<!-- 题解 -->
直接搜索分法是指数级的。换个角度：**答案在 `[max(a), sum(a)]` 之间，并且有单调性**——如果每段上限是 `x` 时能分成不超过 `k` 段，那么上限更大时也一定能。于是把"求最小的最大值"变成"判定 `x` 是否可行"，再在答案空间上二分。

判定函数 `chunks(x)` 是贪心的：从左到右累加，超过 `x` 就开新的一段。贪心在这里是最优的，因为每段尽量装满不会让后面更糟。

时间 O(n log(sum))，空间 O(1)。同类题：运送包裹的最低运力、爱吃香蕉的珂珂、制作花束所需的最少天数——都是"最小化最大值"或"最大化最小值"。
