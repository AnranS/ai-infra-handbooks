1. `partition_labels(s)`：把字符串划分成尽可能多的片段，**同一个字母只能出现在一个片段里**，返回每个片段的长度；
2. `merge_ranges(pairs)`：给定若干 `(start, end)` 闭区间，把有交集的合并（端点相接也算有交集），返回合并后按起点排序的列表。

```python
partition_labels("ababcbacadefegdehijhklij")    # [9, 7, 8]
merge_ranges([(1, 3), (2, 4), (6, 8)])          # [(1, 4), (6, 8)]
```

<!-- 题解 -->
划分字母区间的关键一步：先记下**每个字母最后出现的位置**。然后扫描时维护当前片段必须延伸到的边界 `end = max(end, last[ch])`；走到 `i == end` 就可以切一刀。这是"区间合并"的变体——每个字母对应一个"从第一次出现到最后一次出现"的区间，答案就是合并后的区间长度。

`merge_ranges` 是标准的区间合并：按起点排序，能接上就扩展右端点。注意这里"端点相接也算有交集"（`(1,2)` 和 `(2,3)` 要合并成 `(1,3)`），所以条件是 `start <= 当前右端点`；如果题目说相接不算，就要用 `<`。

工程对应：日志里按会话切分、把有重叠的时间窗口合并成一个批次、以及前缀缓存里"哪些请求共享同一段前缀"的归并。
