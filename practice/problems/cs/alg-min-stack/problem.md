设计一个栈，`push`、`pop`、`top`、`get_min` 都是 O(1)：

- `push(x)`、`pop()`（弹出并返回栈顶）、`top()`（返回栈顶，不弹出）、`get_min()`（返回当前栈里的最小值）；
- 栈为空时 `pop`、`top`、`get_min` 都返回 `None`。

```python
s = MinStack()
s.push(-2); s.push(0); s.push(-3)
s.get_min()      # -3
s.pop()          # -3
s.get_min()      # -2
```

<!-- 题解 -->
关键是"最小值"要能随着弹栈**恢复**。用一个辅助栈同步记录"到这一层为止的最小值"：`push` 时压入 `min(x, 当前最小)`，`pop` 时两个栈一起弹。空间 O(n)，所有操作 O(1)。

更省空间的写法是辅助栈只在"新值 ≤ 当前最小"时才压入，`pop` 时只有"弹出的值等于辅助栈顶"才同步弹出——注意这里必须用 `≤` 和 `==`，否则有重复最小值时会提前把它弹掉。

同类的设计题：最大栈、用两个栈实现队列、用队列实现栈、带 `get_max` 的滑动窗口（单调队列）。它们的共同思路都是"再维护一个结构，让要查询的量可以 O(1) 拿到、并且能随操作回滚"。
