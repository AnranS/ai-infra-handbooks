1. `lis_dp(nums)`：O(n²) 的动态规划版本，返回最长**严格递增**子序列的长度；
2. `lis_fast(nums)`：O(n log n) 的贪心 + 二分版本，返回同样的长度（不能用 `bisect`，自己写二分）。

```python
lis_dp([10, 9, 2, 5, 3, 7, 101, 18])      # 4：[2,3,7,101]
lis_fast([0, 1, 0, 3, 2, 3])              # 4
```

<!-- 题解 -->
DP 版本：`f[i]` 表示**以 i 结尾**的最长长度，转移是 `f[i] = max(f[j]) + 1`（所有 `j < i` 且 `nums[j] < nums[i]`），答案取 `max(f)`。注意状态定义是"以 i 结尾"而不是"前 i 个"，所以答案不是 `f[n-1]`。

快速版本维护一个数组 `tails`，`tails[k]` 表示"长度为 k+1 的递增子序列中，结尾最小的那个值"。它一定是递增的，所以可以二分：新元素用 `lower_bound` 找到第一个 `>= x` 的位置替换掉（保持结尾尽量小），找不到就追加。**`tails` 本身不是答案序列**，但它的长度就是答案。

要非严格递增（允许相等）时，把二分换成 `upper_bound`（第一个 `> x`）。这个区别是常见的追问。
