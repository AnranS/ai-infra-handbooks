实现带**路径压缩**和**按大小合并**的并查集：

- `DSU(n)`：`n` 个元素，编号 `0..n-1`，初始各自成组；
- `find(x)`：返回 x 所在组的代表元；
- `union(a, b)`：合并两组，返回是否真的发生了合并（本来就同组返回 `False`）；
- `count()`：当前有几个组；
- `size(x)`：x 所在组的大小。

再用它实现 `count_components(n, edges)`（无向图的连通分量个数）和 `has_cycle(n, edges)`（无向图是否有环）。

```python
d = DSU(5)
d.union(0, 1); d.union(3, 4)
d.count()        # 3：{0,1}、{2}、{3,4}
d.size(0)        # 2
count_components(5, [(0, 1), (3, 4)])    # 3
has_cycle(3, [(0, 1), (1, 2), (2, 0)])   # True
```

<!-- 题解 -->
两个优化缺一不可：**路径压缩**让 `find` 沿途的节点直接挂到根上（树变平），**按大小合并**把小树挂到大树下（避免长歪）。合用之后单次操作近似 O(1)（反阿克曼函数）。

无向图判环很简洁：遍历每条边，如果两个端点**已经在同一组**，这条边就构成了环；否则合并。连通分量个数就是 `count()`。

工程上的对应：判断集群的分区是否连通、把"同一个用户的多个会话"归并、Kruskal 求最小生成树、编译器里的等价类合并。注意并查集**只能合并不能拆分**，需要删除时要换别的结构。
