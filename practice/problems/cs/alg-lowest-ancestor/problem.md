给二叉树和两个节点 `p`、`q`（都保证存在于树中），返回它们的最近公共祖先节点。再实现一个 `max_depth(root)` 返回树的最大深度。

```python
# 树：3(5(6, 2(7, 4)), 1(0, 8))
# lowest_ancestor(root, 节点5, 节点1) -> 节点3
# lowest_ancestor(root, 节点5, 节点4) -> 节点5（一个节点可以是自己的祖先）
```

<!-- 题解 -->
后序遍历的经典应用：递归地问左右子树"你那边有没有 p 或 q"。

- 当前节点就是 `p` 或 `q`：返回自己（一个节点可以是自己的祖先）；
- 左右子树各返回了一个非空：当前节点就是最近公共祖先；
- 只有一边非空：把那一边的结果往上传。

一次遍历 O(n)、空间 O(树高)。如果是**二叉搜索树**，可以利用有序性：从根往下走，两个值都比当前小就往左、都比当前大就往右，第一个"分叉"的节点就是答案，O(树高) 且不需要递归。

面试常见追问：（1）节点带父指针怎么做（转化成两条链表求交点）；（2）要求 O(1) 空间；（3）不保证两个节点都存在（要额外记录是否都找到了）。
