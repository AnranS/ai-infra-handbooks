找出数组里所有和为 0 的**不重复**三元组，每个三元组内部按升序排列，返回的列表按字典序升序。

```python
three_sum([-1, 0, 1, 2, -1, -4])     # [[-1, -1, 2], [-1, 0, 1]]
three_sum([0, 0, 0, 0])              # [[0, 0, 0]]
three_sum([1, 2, 3])                 # []
```

<!-- 题解 -->
三层循环是 O(n³)。**先排序**，然后固定第一个数、对剩下的部分用相向双指针找"两数之和等于 -a[i]"，降到 O(n²)。

去重是这道题真正的难点，三处都要处理：（1）第一个数和前一个相同就跳过；（2）找到一组解之后，左指针要跳过所有相同的值；（3）右指针同理。只在第一层去重是不够的。

另外两个剪枝：排序后如果 `a[i] > 0` 就可以直接结束（后面都是正数，和不可能为 0）；如果 `a[i] + a[i+1] + a[i+2] > 0` 也可以结束。O(n²) 的常数因此小很多。
