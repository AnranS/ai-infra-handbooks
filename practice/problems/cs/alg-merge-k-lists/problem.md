合并 `k` 条升序链表，返回合并后的升序链表。用 `Node` 类（`val`、`next`）。

```python
# [1->4->5, 1->3->4, 2->6]  合并成  1->1->2->3->4->4->5->6
```

<!-- 题解 -->
两种标准解法：

1. **最小堆**：把每条链表的头节点放进堆，每次弹出最小的、接到结果后面，再把它的后继放进堆。时间 O(N log k)（N 是总节点数），空间 O(k)。注意 Python 的 `heapq` 比较元组时会比较第二个元素，而 `Node` 不能比较大小，所以要放 `(值, 序号, 节点)`，用序号打破平局。
2. **两两归并**：像归并排序一样，每一轮把相邻两条合并，log k 轮之后剩一条。时间同样是 O(N log k)，不需要堆。

朴素做法是"拿结果和下一条合并"，那是 O(Nk)，k 大时明显更慢。

这就是外排序里的**多路归并**：每个分片内部有序，用堆合并成全局有序。推理系统里对应"多个 rank 各自产出的结果按请求顺序合并"，以及分布式 KV 存储的多路读取。
