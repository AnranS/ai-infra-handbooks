给定整数数组 `nums` 和目标值 `target`，返回两个**下标** `(i, j)`（`i < j`）使 `nums[i] + nums[j] == target`。保证有且只有一组答案。

```python
two_sum([2, 7, 11, 15], 9)      # (0, 1)
two_sum([3, 2, 4], 6)           # (1, 2)
```

<!-- 题解 -->
两层循环是 O(n²)。用哈希表把"找 target - x 在不在前面出现过"变成 O(1)：边遍历边记录 `值 -> 下标`，遇到 `target - x` 已经在表里就直接返回。

两个细节：（1）**先查后存**，否则 `[3, 3]`、`target = 6` 时会把自己和自己配对；（2）同一个值出现多次时，表里存的是最近一次的下标，不影响正确性（题目保证只有一组答案）。

这是"用哈希表消除一层循环"的最小例子，后面很多题都是它的变体：三数之和（排序 + 双指针）、两数之差、子数组和为 k（前缀和 + 哈希表）。
