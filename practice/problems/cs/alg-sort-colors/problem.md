数组里只有 0、1、2 三种值，**原地**把它们排成 0 在前、1 在中、2 在后。只能遍历**一遍**、O(1) 额外空间（不能用排序，也不能先计数再重写）。

```python
a = [2, 0, 2, 1, 1, 0]
sort_colors(a)
a                      # [0, 0, 1, 1, 2, 2]
```

<!-- 题解 -->
荷兰国旗问题。三个指针：`low` 指向下一个 0 该放的位置，`high` 指向下一个 2 该放的位置，`i` 是当前扫描位置。

- `a[i] == 0`：和 `low` 交换，`low += 1`、`i += 1`（换过来的一定是已经处理过的 1）；
- `a[i] == 2`：和 `high` 交换，`high -= 1`，**`i` 不动**（换过来的元素还没检查过）；
- `a[i] == 1`：`i += 1`。

最容易错的就是"换 2 之后 i 不能前进"。循环条件是 `i <= high`。

这个三向划分也是快速排序处理大量重复元素的关键（三路快排），以及推理系统里"按状态把请求分成待调度/运行中/已完成三段"的常用写法。
