带权有向图（权非负），`edges` 是 `[(a, b, w), ...]`。实现：

1. `dijkstra(n, edges, start)`：返回一个列表，第 i 个元素是从 `start` 到 i 的最短距离，不可达为 `None`；
2. `network_delay(n, edges, start)`：信号从 `start` 传到**所有**节点需要的时间（有节点到不了返回 -1）。

```python
dijkstra(4, [(0, 1, 1), (1, 2, 2), (0, 2, 5), (2, 3, 1)], 0)   # [0, 1, 3, 4]
network_delay(4, [(0, 1, 1), (1, 2, 2), (0, 2, 5), (2, 3, 1)], 0)   # 4
```

<!-- 题解 -->
用小顶堆每次取出"当前距离最小的未确定节点"，松弛它的所有出边。Python 的 `heapq` 不支持"降低优先级"，所以用**惰性删除**：直接把新的 `(距离, 节点)` 压进堆，弹出时如果这个距离已经不是最新的就跳过。时间 O((V+E) log V)。

两个坑：（1）弹出时要检查 `d > dist[node]` 并跳过，否则同一个节点会被重复展开；（2）距离用 `float("inf")` 初始化，最后再把不可达的换成 `None`。

Dijkstra 要求**边权非负**（负权会让"已确定"的结论失效，要用 Bellman-Ford）。边权只有 0 和 1 时可以用 0-1 BFS（双端队列）代替堆。

工程对应：集群里选一条延迟最低的路由路径、KV 传输选最优链路、以及"多跳转发"的代价估算。
