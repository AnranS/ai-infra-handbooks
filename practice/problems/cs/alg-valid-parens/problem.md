判断只含 `()[]{}` 的字符串是否有效：括号必须以正确的顺序闭合。再实现一个 `longest_valid(s)`，返回最长有效括号子串的长度（只含 `(` 和 `)`）。

```python
is_valid("()[]{}")        # True
is_valid("([)]")          # False
longest_valid(")()())")   # 4
```

<!-- 题解 -->
`is_valid` 是栈的入门题：左括号入栈，右括号就检查栈顶是否是配对的左括号。两个边界：**栈空时遇到右括号**要直接返回 False；**遍历结束栈非空**也是 False。

`longest_valid` 有个巧妙的栈写法：栈里存**下标**，初始放一个 `-1` 当"最后一个未匹配右括号的位置"。遇到 `(` 就压下标；遇到 `)` 就弹栈，弹完如果栈空，说明这个 `)` 没人配对，把它的下标压进去当新的基准；否则当前有效长度是 `i - 栈顶`。

另一种解法是动态规划（`dp[i]` 表示以 i 结尾的最长有效长度），也可以左右各扫一遍用计数器做到 O(1) 空间。面试里能说出两种解法是加分项。
