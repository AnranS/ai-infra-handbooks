用单调栈实现两个函数：

1. `daily_temperatures(t)`：对每天返回"还要等几天才会遇到更高的温度"，没有则为 0；
2. `trap(height)`：柱状图能接多少雨水。

```python
daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73])   # [1, 1, 4, 2, 1, 1, 0, 0]
trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])             # 6
```

<!-- 题解 -->
两题共用同一个模板：**栈里存下标，栈内对应的值单调不增**。新元素比栈顶大时，栈顶元素"找到了右边第一个更大的"，弹出并结算。

`daily_temperatures` 的结算是下标之差。`trap` 的结算要用三根柱子：弹出的那根是"底"，新的栈顶是左墙，当前元素是右墙，接水量 = `(min(左墙, 右墙) - 底) * 宽度`。

接雨水还有一个更短的**双指针**解法：左右各一个指针和一个"已知的最大高度"，每次移动较矮的一侧，当前位置能接的水就是"该侧最大高度 - 当前高度"。O(1) 空间。面试时先写单调栈（通用模板），再提双指针（更优）是很好的展开。

复杂度都是 O(n)：每个下标进栈一次、出栈一次。
