# 从零训练一个小模型

<p class="lead">这本小册子从一个空目录开始，在自己的电脑上训练一个会写《三国演义》的小语言模型：准备语料、训练分词器、写模型和训练循环、评估与生成，再把它训得更快、更大；接着做指令微调，让它按对话的格式回答，用 LoRA、DPO 和蒸馏走一遍后训练，并导出成现成推理框架能直接加载的格式；最后换到一张消费级显卡上看看一晚上能训出什么——文本模型和图像生成模型各一个。全部代码都真实运行过，主线在 CPU 上约 6 分钟跑完。真实的训练只是多了几个数量级的数据和算力，流程是同一个。</p>

## 快速开始

先把它跑起来，再回头看每一步为什么这么做。只要 CPU，主线五个脚本一共约 **6 分钟**。

```bash
# ① 环境：CPU 版 PyTorch（2.4 以上）与 tokenizers
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install tokenizers

# ② 新建一个空目录，把各页里带文件名的代码块复制进去（每页右上角也能下载成 notebook）
mkdir mylm && cd mylm

# ③ 按顺序跑，前一个脚本的产出留给后一个
python prepare.py        # （一）语料 → BPE 分词器 → token 序列
python train.py          # （二）训练一个 1.8M 的小 GPT，它会写《三国演义》风格的句子
python chat_data.py      # （四）从同一份语料造指令数据
python sft.py            # （四）指令微调，它开始按对话的格式回答
python export.py         # （五）导出成 LLaMA 的权重布局

# ④ 跟它说句话
python talk.py
```

训完之后它是这样的——三问三答都是真实的，模型一共 1.8M 参数，只读过一本《三国演义》：

```text
你：这句话是谁说的：「吾自有计。」
模型：操

你：接下来写：玄德大喜，遂引兵而进。
模型：次日，人报魏兵溃散。

你：「操大怒，拔剑欲斩之。」的下一句是什么？
模型：孔明
```

答得对不对另说，但它确实在按对话的格式回答、而且知道在哪停。真实的模型只是把数据和算力各放大几个数量级，流程是同一个。

其余脚本都是**实验**：量时间、验证等价性、比较几种做法。它们不产出主线要用的文件，挑着跑、或者只看页面上的输出都可以。

## 这本书适合谁

- 读过 Transformer 的结构、会写 PyTorch，但还没有亲手训练过一个语言模型；
- 想能说"我从零训过一个模型"，并且讲得清每一步在干什么、时间花在哪里；
- 手上只有一台笔记本或一张消费级显卡，想知道这点算力能做到什么。

读完并跟着做完，你应该能：

- 从一份纯文本开始训练 BPE 分词器，解释词表大小怎么权衡；
- 写出一个 pre-norm 的小 GPT 和完整的训练循环（学习率调度、梯度裁剪、验证、checkpoint、续训、生成）；
- 测出一步的时间花在哪里、算力用上了多少，并用梯度累积、`torch.compile`、混合精度、DDP 把它训得更快更大；
- 写出聊天模板、把 loss 只算在助手的回答上，把基座模型微调成会按格式作答的小助手；
- 从零写出 LoRA、DPO 和白盒蒸馏，讲清每一件在改什么、代价是什么，并把模型导出给推理框架；
- 为一张 16 GB 的卡算出显存账本，知道能放下多大的模型、训一晚上能到什么程度。
