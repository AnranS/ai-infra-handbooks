# 从零训练一个小模型

<p class="lead">这本小册子从一个空目录开始，在自己的电脑上训练一个会写《三国演义》的小语言模型：准备语料、训练分词器、写模型和训练循环、评估与生成，再把它训得更快、更大，最后换到一张消费级显卡上看看一晚上能训出什么——文本模型和图像生成模型各一个。全部代码都真实运行过，CPU 上一次训练约 3 分钟。真实的预训练只是多了几个数量级的数据和算力，流程是同一个。</p>

## 这本书适合谁

- 读过 Transformer 的结构、会写 PyTorch，但还没有亲手训练过一个语言模型；
- 想能说"我从零训过一个模型"，并且讲得清每一步在干什么、时间花在哪里；
- 手上只有一台笔记本或一张消费级显卡，想知道这点算力能做到什么。

读完并跟着做完，你应该能：

- 从一份纯文本开始训练 BPE 分词器，解释词表大小怎么权衡；
- 写出一个 pre-norm 的小 GPT 和完整的训练循环（学习率调度、梯度裁剪、验证、checkpoint、续训、生成）；
- 测出一步的时间花在哪里、算力用上了多少，并用梯度累积、`torch.compile`、混合精度、DDP 把它训得更快更大；
- 为一张 16 GB 的卡算出显存账本，知道能放下多大的模型、训一晚上能到什么程度。
